# User flows

## FLOW-01 Split a bill with a quick tip

1. User opens the Tip Splitter page on a phone or desktop
2. User enters the bill amount
3. User taps a quick tip button (10%, 15% or 20%)
4. User enters the number of people
5. App immediately shows the tip, the total and the amount per person

## FLOW-02 Split a bill with a custom tip

1. User enters the bill amount and the number of people
2. User types a custom tip percentage into the custom field
3. App immediately shows the tip, the total and the per-person amount using the custom percentage

## FLOW-03 Correct invalid input

1. User enters an invalid value (e.g. empty, negative, non-numeric bill, or 0 / fractional people)
2. App shows a clear message naming the problem field and shows no computed amounts
3. User corrects the value
4. Message disappears and results appear right away
